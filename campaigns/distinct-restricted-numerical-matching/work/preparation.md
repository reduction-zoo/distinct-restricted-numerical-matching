# Prepare evidence

Prepared 2026-09-26. The fixed corpus has 120 distinct 3-SAT formulas: 20 hand cases and 100 reproducible seeded random cases, with 64 YES and 56 NO. Formula sizes range from 0 to 6 variables. `generate_cases.py` fixes the inputs and seeds before any candidate construction.

Run `uv sync --locked` and `uv run --locked python campaigns/distinct-restricted-numerical-matching/work/check.py --self-test`. The check first runs the copied `research/validate_preparation.py`, regenerates random cases, recomputes labels with Z3, validates satisfying assignments directly, and compares SAT decisions with exhaustive assignments. Target Z3 variables encode the two permutations and row-sum equations. Every satisfying model is checked directly. A separate enumeration of all first permutations derives each possible second permutation arithmetically, crosschecking 486 balanced target instances with up to four rows. Only `unsat` is a negative result; `unknown` raises an error. Hand fixtures include feasible and infeasible targets, invalid promises and bad witnesses. The self-test passed. An intentionally incorrect candidate returning a feasible one-row target and always extracting `NO-SOLUTION` was rejected.

Oracle: CPython 3.12.14 and locked `z3-solver` 4.16.0.0. The target crosscheck is finite: up to four rows and values from `1..2n`. The candidate gate checks up to three target solutions per source instance, not every possible target witness. No reduction, general proof or solution is claimed; zero construction rounds were authorized for this setup.
